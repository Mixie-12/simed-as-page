# Simed AS – nettsidemal (HTML/CSS/JS)

Dette er en moderne, responsiv nettside med flere sider, animasjoner og enkel kontaktform (mailto).
Ingen byggesteg kreves.

## Struktur
- `index.html` - Forside med hero-seksjon
- `om.html` - Om selskapet
- `team.html` - Team-side med medlemsprofiler
- `mandat.html` - Investeringsmandat
- `prosess.html` - Investeringsprosess
- `risiko.html` - Risikostyring
- `baerekraft.html` - Bærekraft og ansvarlighet
- `kontakt.html` - Kontaktskjema
- `styles.css` - Styling med animasjoner og effekter
- `scripts.js` - JavaScript for animasjoner og interaktivitet
- `assets/favicon.svg` - Favicon

## Funksjoner
- Multi-page navigasjon
- Følg-mus-peker animasjon (cursor dot)
- Glass morphism effekter på hover
- Dynamiske inngående animasjoner
- Responsivt design for mobil og desktop
- Smooth scroll og reveal-on-scroll animasjoner
- Mobil meny

## Slik kjører du
Bare åpne `index.html` i nettleseren.

Tips: For lokal utvikling kan du bruke en enkel server (for eksempel VS Code Live Server eller `python3 -m http.server`).

## Hva du bør endre
- E‑post: `kontakt@simed.no` (i `kontakt.html` og `scripts.js`)
- Organisasjonsnummer (i kontaktseksjonen)
- Team-medlemmer med riktige navn og informasjon (i `team.html`)
- Eventuelle lenker til personvern / vilkår hvis dere ønsker det

## Mer
Designet er skalerbart og kan enkelt utvides med flere sider etter behov.
