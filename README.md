# Simed AS – nettsidemal (HTML/CSS/JS)

Dette er en moderne, responsiv «one‑pager» med animasjoner og enkel kontaktform (mailto).
Ingen byggesteg kreves.

## Struktur
- `index.html`
- `styles.css`
- `scripts.js`
- `assets/favicon.svg`

## Slik kjører du
Bare åpne `index.html` i nettleseren.

Tips: For lokal utvikling kan du bruke en enkel server (for eksempel VS Code Live Server),
men det er ikke nødvendig.

## Hva du bør endre
- E‑post: `kontakt@simed.no` (i `index.html` og `scripts.js`)
- Organisasjonsnummer (i kontaktseksjonen)
- Eventuelle lenker til personvern / vilkår hvis dere ønsker det

## Mer
Ønsker du flere sider (f.eks. «Kontakt», «Investor» eller «Nyheter») kan samme design utvides enkelt.
